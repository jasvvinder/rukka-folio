# 05 — Account-name presets

**Status:** Draft, 20 Oct 2026. English only: each name needs ਪੰਜਾਬੀ and हिन्दी from native review, never from machine translation, and a name is offered once all three exist.

This is one list of common account names, grouped by the **account type** the user picks. It is not split by kind of book: a household, a shop, a farm and a trust all see the same chips. When the user creates an account, the app offers the names for that type as one-tap chips. One tap fills in the name, the user can still edit it, and nothing is created until they confirm. They can also ignore the chips and type their own name.

Where the chips appear:
- **New A/C wizard, step 2** (07 §6): chips for the type tile chosen in step 1.
- **Entry picker** (07 §5 step 3): chips for the slot's inferred type (02 §1.2). *For what?* on Money out shows Expense chips; *From what?* on Money in shows Income chips. Typing filters the chips.

Rules for the chips:
- Names the book already has are hidden.
- Chips appear in the app's current language. Once an account is created, its name belongs to the user and is never translated or renamed by the app.
- The name is stored as shown, with no *A/c* suffix, the same as a name the user types.
- No chips for a person or shop, because their name can't be guessed. No chips for Capital either, because the app creates it.
