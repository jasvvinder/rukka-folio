02

The story

Four beats, in cause-and-effect order. Nothing appears that wasn't already there; nothing leaves the book.

Opening: the strap and seal contract together and tuck left — unfastened, smaller, still present (sealed is always one gesture away). The top-right corner folds down into a dog-ear: the page now in use. The entries sweep leftward into the cleared space, revealed as the closure moves aside. A third entry writes itself in, left to right — an open book is a book being written.

Sealing is the exact reverse: the new entry retreats, the entries pull back, the corner flattens, and the strap and seal return to full size last. It should feel like putting the books away properly.

Always

  • The open state is earned — only after a real unlock
  • Respect prefers-reduced-motion: jump cut, no tween
  • Keep the beat order — the stagger is the story
  • Scale timing only via m

Never

  • Play the animation decoratively or on a repeating loop in shipped UI
  • Animate on the auth prompt — only on success
  • Let any element exit the book bounds
  • Recolour, add bounce/overshoot, or add new elements

Implementation notes

Strap, seal and entries are plain CSS: transform on strap and seal, geometry-property transitions (x, width) on the entry rects — no library needed; the CSS in this page's source is the canonical reference. The dog-ear is a path morph between M14 14 H74 L74 14 V74 H14 Z and M14 14 H62 L74 26 V74 H14 Z (with the fold triangle fading in). The path sits 2 units inside the book bounds and carries a same-colour 4-unit stroke with round joins, so its effective outline is exactly the 12–76 book with r5 corners. This page drives the morph with ~20 lines of JS. For production, rebuild the whole sequence as one Rive or Lottie asset so mobile and web share a single file, and keep this page as the acceptance reference.
