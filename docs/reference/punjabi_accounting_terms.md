# Professional Accounting Terms in Punjabi

This document contains a comprehensive list of professional accounting, bookkeeping, and financial terms in Punjabi, spanning both modern corporate accounting and traditional Indian mercantile systems (*Bahi Khata*).

---

## 📊 Assets & Liabilities (ਸੰਪੱਤੀ ਅਤੇ ਦੇਣਦਾਰੀਆਂ)

| English Term | Punjabi Accounting Term (Gurmukhi) | Transliteration (Pronunciation) |
| :--- | :--- | :--- |
| **Assets** | ਸੰਪੱਤੀ / ਜਾਇਦਾਦ | *Sampatti / Jaidad* |
| **Liabilities** | ਦੇਣਦਾਰੀਆਂ / ਜ਼ਿੰਮੇਵਾਰੀਆਂ | *Daindaarian / Zimmawaarian* |
| **Cash in Hand** | ਰੋਕੜ ਬਾਕੀ / ਹੱਥਲੀ ਰੋਕੜ | *Rokad Baaki / Hathli Rokad* |
| **Cash at Bank** | ਬੈਂਕ ਬਾਕੀ / ਬੈਂਕ ਰੋਕੜ | *Bank Baaki / Bank Rokad* |
| **Sundry Debtors** | ਦੇਣਦਾਰ / ਅਸਾਮੀ | *Daindaar / Asaami* |
| **Sundry Creditors** | ਲੈਣਦਾਰ / ਸ਼ਾਹੂਕਾਰ | *Laindaar / Shahookar* |
| **Stock in Hand** | ਮਾਲ ਬਾਕੀ / ਸਟਾਕ | *Maal Baaki / Stock* |
| **Capital** | ਪੂੰਜੀ / ਸਰਮਾਇਆ | *Poonji / Sarmaaya* |

## 📈 Income & Expenses (ਆਮਦਨ ਅਤੇ ਖਰਚੇ)

| English Term | Punjabi Accounting Term (Gurmukhi) | Transliteration (Pronunciation) |
| :--- | :--- | :--- |
| **Income / Revenue** | ਆਮਦਨ / ਕਮਾਈ | *Aamdan / Kamaai* |
| **Expenses / Expenditure** | ਖਰਚੇ / ਲਾਗਤ | *Kharche / Laagat* |
| **Gross Profit** | ਕੁੱਲ ਮੁਨਾਫਾ | *Kull Munafa* |
| **Net Profit** | ਸ਼ੁੱਧ ਮੁਨਾਫਾ / ਖਰਾ ਨਫਾ | *Shuddh Munafa / Khara Nafa* |
| **Net Loss** | ਸ਼ੁੱਧ ਨੁਕਸਾਨ / ਘਾਟਾ | *Shuddh Nuksaan / Ghaata* |
| **Drawings (Personal use)** | ਨਿੱਜੀ ਖਰਚਾ / ਖਾਤਾ ਘਰੂ | *Nijji Kharcha / Khata Gharoo* |

---

## 💡 Pro-Tip for Punjabi Bookkeeping
When recording transactions in traditional formats, accountants often write **"ਨਾਮੇ" (Naame)** for amounts to be debited and **"ਜਮ੍ਹਾਂ" (Jammah)** for amounts to be credited to a specific account header.
